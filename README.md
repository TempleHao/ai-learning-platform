# AI Learning OS

> 从 AI 初学者到 AI 运用层专家的长期学习系统。

这个仓库用于构建一个可持续迭代的 AI 学习平台。它不是一次性“AI 教程”，而是把 **历史、技术路线、能力、应用、构建、商业、未来、风险与实战** 放进同一套知识系统。

## 当前版本

**v0.13 · AI-native Organization 已发布**

平台已经形成“主干教材 + Deep Dive + Lab + 案例库 + Frontier Radar + Review + 延伸阅读 + 超文本探索”的完整学习骨架，并进入持续深化阶段。

## 项目原则

1. **地图优先**：先建立全局坐标，再深入术语。
2. **路线竞争**：不仅讲成功路线，也讲失败、放弃和重新复兴的路线。
3. **能力导向**：不追着产品名学习，而是跟踪 AI 能力边界的变化。
4. **价值导向**：应用研究同时分析经济价值与社会价值。
5. **商业判断**：研究软件、硬件、基础设施、产业和学界交叉机会。
6. **风险贯穿**：可靠性、安全、治理、劳动与社会影响不是附录。
7. **版本化更新**：稳定知识与快速变化的前沿内容分层维护。
8. **必须实战**：每个阶段留下可验证的作品，而不是只阅读。
