# Lab 12 · AI for Science / Physical AI 机会尽调

Reviewed: 2026-10-08 · 适合桌面研究，无需真实机器人操作。

## 目标
从一个真实项目出发，判断 AI 预测、实验验证、物理部署和商业价值之间的证据链是否闭合。最终提交 2–4 页可复核的 Go / No-Go 备忘录。

## 输入
- 选择一个项目：生物分子研究工具、材料发现、仓储机器人、自动驾驶或其他实体智能应用。
- 至少 3 个一手来源：论文、官方技术文档、监管材料或可核查的公开测试。
- 明确非 AI 基线：现有人工、软件或传统自动化如何完成任务，成本与成功率如何。

## 证据矩阵
对每项主张标注证据级别：
- E0：营销陈述或无来源；
- E1：受控演示或内部基准；
- E2：重复实验或公开可复核的试点；
- E3：独立复现或长期现场运营数据。

逐条写出：主张、证据来源、样本/时间/ODD、验证者、失效条件。企业自报数据必须明确标注。

## 五个尽调门槛
1. **需求**：谁使用，愿意为哪项成果付费？
2. **技术**：核心预测或控制能力在哪些数据/环境下有效？
3. **环境**：场景可控程度、变化来源、Sim-to-Real Gap？
4. **安全**：风险负责人、监管义务、停止条件、人工接管？
5. **经济**：每个已验收任务的全部成本及资本开支？

## 量化框架
- 任务成功率 = 验收成功任务 / 全部尝试任务。
- 人工接管率 = 需要人工介入的任务 / 全部任务。
- 单位有效任务成本 =（设备折旧 + 能源 + 软件 + 维护 + 集成摊销 + 人工接管 + 失败损失）/ 验收成功任务数。
- 科学场景另计：每个实验验证候选的成本、失败实验比例、从筛选到实验结果的周期。

不要用实验室模型准确率代替真实任务成功率；也不要将安全指标直接压缩成商业评分。

## 必须交付
- 3 个可证伪假设：例如“受控试点中每 100 次任务的接管不超过 X 次”。
- 5 个具体失败场景，至少一个涉及长尾分布变化，一个涉及安全或监管。
- 3 项必须实测的指标，给出采集方法、样本范围和验收阈值。
- 明确决策：Go（继续验证）、Narrow（缩小范围）或 No-Go（暂缓），写出下一轮需要的证据。

## 自反馈
完成后复核：有没有把预测当成实验？有没有把企业自报当成独立结论？有没有遗漏折旧和人工接管？有没有将局部 ODD 结果外推到开放世界？下一轮优先补哪条证据？
