# AI Learning OS · 完整框架

## 四个贯穿问题

1. **AI 从哪里来？** 前世今生、主要/次要路线、没有被选择的路线，以及路线胜负背后的原因。
2. **AI 能做什么？** 关键能力跃迁、成功应用、工作流变化、经济价值与社会价值。
3. **未来会怎样？** 用情景树研究模型、Agent、机器人、软硬件、基础设施和学界产业化机会。
4. **风险在哪里？** 技术可靠性、安全、隐私、版权、就业、权力结构、治理和前沿系统性风险。

## 10 大模块

### 00 · 项目起点与世界地图
建立 AI → ML → Deep Learning → Foundation Model → LLM → Multimodal → Reasoning → Agent → Robotics 的整体关系。

### 01 · 基础原理
模型、参数、训练、推理、数据、算力、Token、上下文；数学只深入到理解 AI 所需要的程度。

### 02 · AI 前世今生与路线竞争
符号主义、连接主义、统计学习、概率方法、强化学习、深度学习、Transformer、生成模型与 Foundation Model。

### 03 · AI 能力地图
语言、视觉、语音、生成、搜索、预测、代码、推理、规划、工具调用、长期任务、科学研究与物理世界控制。

### 04 · AI 应用演进
专家系统 → 搜索 / 广告 / 推荐 → 视觉 / 语音 → 生成式 AI → Copilot → Agent → AI Scientist / Robotics。

### 05 · AI 运用与构建
Prompt → Context Engineering → 文件与搜索 → RAG → API → 自动化 → Agent → Eval → 可靠性与成本控制。

### 06 · AI 商业机会
能源和数据中心、芯片与 HBM、云和模型、Agent 基础设施、AI SaaS、垂直 AI、AI-native 服务、机器人、AI for Science、安全和评测。

### 07 · 未来演变
建立多套情景树和领先指标，用持续证据修正对 AGI 与产业未来的判断。

### 08 · 风险与治理
幻觉、鲁棒性、Agent 权限、网络安全、隐私、版权、就业、技能退化、信息生态、垄断、军事竞争和控制问题。

### 09 · 实战实验室
技术路线图、Context Engineering 对比实验、个人知识库 / RAG、工具型 Agent、行业机会分析、0→1 AI 产品。

### 10 · 参考与版本系统
术语表、资料来源规范、更新日志、知识卡片、版本标记与前沿雷达。

## 三层知识架构

### Stable
相对稳定的基础知识：核心概念、经典方法、重要历史、底层经济逻辑。

### Frontier
快速变化的知识：模型能力、价格、Agent、芯片、企业、融资、监管、市场结构。所有内容带时间戳和来源。

### Lab
个人实践：Prompt、工作流、代码、实验、失败记录、产品原型、评测结果与复盘。
