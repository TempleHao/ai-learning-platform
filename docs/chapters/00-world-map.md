# 第 0 章：AI 世界全地图

> Stable Core。目标：先建立概念坐标，热点只作为案例和前沿信号。

## 学习目标

学完后，应能不用术语堆砌，解释 AI、机器学习、深度学习、基础模型、大语言模型、多模态、推理、Agent 与机器人之间的关系，并能区分“模型能力”和“产品系统”。

## 0.1 AI 是什么

AI 是一个宽泛领域，不等同于聊天机器人。NIST 的一个定义将 AI 描述为机器系统：针对人类定义的目标，产生影响现实或虚拟环境的预测、建议或决策。

判断 AI 能力时，重点看机器能否完成感知、表示、学习 / 推理、决策与行动中的一个或多个环节。

## 0.2 必须掌握的包含关系

AI ⊃ Machine Learning ⊃ Deep Learning ⊃ Foundation Models，其中 LLM 是 Foundation Model 的重要类别之一。

注意：Agent、RAG、Multimodal、Reasoning、Robotics 分别属于系统架构、能力形态或软硬件系统，不能简单塞进同一个层级套娃。

## 0.3 模型与产品处在不同层级

完整 AI 产品通常还包括：

1. 用户体验层；
2. 应用 / Agent / Workflow；
3. 一个或多个模型；
4. 数据、训练、后训练与评测；
5. GPU、内存、网络、数据中心与电力等计算基础设施。

商业价值发生在整套系统中，不只发生在模型层。

## 0.4 六类能力

- 感知：视觉、语音、传感器。
- 语言：理解、生成、翻译、总结。
- 预测：分类、排序、推荐、风险评分。
- 生成：文字、图像、音视频、代码。
- 推理与规划：多步问题、数学、代码、计划。
- 行动：工具调用、电脑操作、工作流与物理行动。

## 0.5 极简历史线

- 1950s：AI 成为正式研究领域；1956 Dartmouth 会议具有奠基意义。
- 1960s–1980s：符号主义、搜索、专家系统重要。
- 1990s–2000s：统计机器学习壮大。
- 2010s：深度学习在视觉、语音等领域突破。
- 2017：Transformer 提出。
- 2020s：基础模型、生成式 AI、多模态、推理与 Agent 快速发展。

## 0.6 Frontier Snapshot（2026）

Stanford 2026 AI Index 的数据提示：Agent 在真实计算机任务上明显进步，但可靠性仍不足；机器人在开放真实家庭环境中的表现远弱于数字世界 Agent。当前主线正在从“生成答案”向“可靠执行任务”迁移。

## 0.7 初学者常见误区

AI ≠ ChatGPT；模型 ≠ 数据库；Benchmark ≠ 真实生产表现；Agent ≠ 自动回复；懂 AI ≠ 必须先学会训练大模型。
