# 第 3 章：AI 能力地图与应用演进

## 核心公式

这是定性分析框架：先识别新增任务能力，再测可靠性、单位成本、分发和工作流嵌入；不同单位的指标不可直接相乘得出产业影响。

## 能力阶梯

1. Prediction：分类、排序、概率估计。
2. Perception：视觉、语音、传感器。
3. Generation：生成文本、代码、图像、音视频。
4. Generalization：通过指令和少量示例适应新任务。
5. Reasoning：多步推理、搜索、规划。
6. Tool Use：调用外部搜索、数据库、代码和 API。
7. Agent：围绕目标持续行动和检查。
8. Embodiment：机器人、车辆与物理设备。

能力呈锯齿状发展，不同任务上的提升速度和上限差异很大。以上编号是分类导航，不构成严格的先后等级；预测、感知、生成、工具调用与行动可以组合，单项能力不自动保证其他能力。

## 应用演进

### 专家系统
价值：复制稀缺专家知识。
限制：知识工程和维护成本。

### 搜索 / 广告 / 推荐
价值：降低匹配与决策成本。狭窄预测模型第一次形成超大规模经济价值。

### 视觉 / 语音
2012 后深度学习显著提升感知能力，推动识别、转写、质检与自动驾驶感知。

### Foundation / GenAI
2020 GPT-3 展示通过文字指令与 few-shot 示例完成多种任务；通用自然语言接口降低新任务开发门槛。

### Copilot
2021 GitHub Copilot 技术预览将生成模型直接嵌入 IDE，代表 AI 从独立 Demo 进入工作流。

### Chat / Consumer GenAI
2022 ChatGPT 通过对话界面把生成式 AI 大规模带给普通用户。

### Agent / Physical AI
能力从“生成答案”转向“规划 + 工具 + 行动”。2026 AI Index 显示 OSWorld Agent 成功率约 66.3%，真实家庭机器人任务约 12%，说明数字世界与物理世界仍有巨大鸿沟。

## 六种价值机制

- 降低搜索成本
- 提高匹配效率
- 降低内容生产边际成本
- 提高专家杠杆
- 替代流程执行成本
- 降低物理劳动成本

## 商业机会六问

能力增益、可靠性阈值、价值密度、工作流嵌入、分发与数据、模型吞噬风险。

## 量化练习：客服自动化的单位经济性（虚构教学数据）

月量 1,000 单；全人工每单 12 分钟；人工 60 元/小时；AI 每单 0.6 元。AI 直接处理的单据仍需 4 分钟人工复核；升级人工需 14 分钟。自动处理出错每次平均额外损失 100 元。

令 p 为自动直接处理比例、e 为其条件错误率：每单人工分钟 = 4p + 14(1−p)，月总成本 = 1,000 × [4p + 14(1−p) + 0.6 + 100pe]。全人工月成本 12,000 元。

基准 p=80%、e=5%：人工 6,000 元、模型 600 元、错误损失 4,000 元，AI 月成本 10,600 元，节省 1,400 元；固定 p=80% 的盈亏平衡错误率为 6.75%。p=80%、e=10% 时月成本 14,600 元，亏损 2,600 元；p=50%、e=5% 时月成本 12,100 元，亏损 100 元。上线前必须独立核查质量验收、错误率估计、尾部损失、权限、法规和客户体验。

## Lab

选择一个熟悉行业，画出：新增能力 → 被改造任务 → 被降低的成本 → 谁获取最终价值。用计算器预测并复算 p=80%、e=10% 与 p=50%、e=5% 两组反例，列出至少三项真实上线前的测量指标。完成勾选是自我确认，不自动判分。
