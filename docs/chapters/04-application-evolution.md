# 第 4 章：AI 应用演进史

主线：规则自动化 → 预测自动化 → 内容生成 → 人机协作 → 任务执行 → 物理行动。

关键阶段：
- 专家系统：复制专家知识
- 搜索/广告/推荐：AI 成为互联网利润引擎
- 深度学习：视觉、语音、翻译、感知进入产品
- AlphaGo：复杂决策与搜索
- AlphaFold：AI for Science
- ChatGPT：生成式 AI 大众化
- Copilot：嵌入工作流
- Agent：从建议走向任务执行
- 自动驾驶/机器人：进入物理世界

2026:
- 组织 AI 采用率 88%
- Agent 在业务职能部署仍多数为个位数
- 美国消费者生成式 AI 年度剩余价值估计 1720 亿美元

Sources: Stanford 2026 AI Index, OpenAI, Nature AlphaFold, DeepMind AlphaGo.
