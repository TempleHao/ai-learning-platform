# 第 1 章：AI 技术路线战争

## 核心问题

AI 历史的主线，是围绕“智能从哪里来”展开的路线竞争。

### 五种重要路线
1. 符号主义：智能来自规则、知识、逻辑与搜索。
2. 连接主义：智能来自网络参数在数据中的学习。
3. 统计学习：智能来自对不确定性和数据分布的估计。
4. 强化学习：智能来自行动、反馈与奖励。
5. 其他路线：进化计算、模糊逻辑、概率图模型、类脑计算等。

## 为什么路线会兴衰

评价一条路线时统一考虑：
- 算法
- 数据
- 算力
- 任务性质
- 工程维护成本
- 分发与商业条件

## 关键拐点

- 1956：Dartmouth，AI 作为研究领域成形。
- 1980s：专家系统兴盛又暴露知识工程瓶颈；AI 进入寒冬。
- 1990s–2000s：统计机器学习在真实数据任务中壮大。
- 2012：AlexNet + GPU + ImageNet 形成深度学习产业拐点。
- 2016：AlphaGo 展示深度学习、强化学习和搜索的融合。
- 2017：Transformer 提出。
- 2020s：基础模型与大规模预训练成为主干。

## 核心判断

今天的真实 AI 系统越来越混合：神经模型 + 搜索 / 规划 + 规则 / 权限 + 检索 / 数据 + 反馈 / 评测。

## 2026-11-01 深度审校：分类交叉与路线成本实验

- **定义边界**：符号表示、神经网络、概率估计、强化学习和搜索分别描述不同技术层级，能够交叉组合。五条路线是历史叙事框架，不能理解成互斥类别。
- **一手证据**：2012 AlexNet 论文说明深度卷积网络与 GPU 训练；2016 AlphaGo 原论文的摘要和图 1–3 明确监督学习、自我对弈强化学习、策略/价值网络与树搜索；2017 Transformer 原论文说明序列建模架构和并行训练。论文对应不同问题，不能以单一结果推出所有任务的路线优劣。
- **可复算情景（虚构教学数据）**：10,000 笔交易，100 笔欺诈。规则 R 拦下 60 笔欺诈、误拒 300 笔正常交易、维护 2,000 元；模型 M 拦下 80 笔欺诈、误拒 500 笔正常交易、维护 8,000 元。
- **损失函数**：R = 40L + 300C + 2,000；M = 20L + 500C + 8,000。L=500、C=40 时 R=34,000、M=38,000。固定 L=500 时 M−R=200C−4,000，C=20 为打平点。C=10 时 R=25,000、M=23,000。
- **诊断与迁移**：不能只凭欺诈召回率选方案。需说明误拒、漏判、维护、标签延迟、漂移、人工接管、合规约束和评测样本时间窗。
