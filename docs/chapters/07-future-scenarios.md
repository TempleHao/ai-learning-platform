# 第 7 章：AI 未来情景树

## 核心方法

未来研究采用多情景树，并用领先指标持续修正。

关键驱动力：
- 模型能力
- Agent 可靠性
- 推理成本
- 算力与能源
- 机器人真实任务表现
- 监管与社会接受度

## 四种情景

1. 渐进增强：模型继续变强，但可靠性改善较慢。
2. Agent 跨过可靠性阈值：长流程和电脑操作进入主流生产。
3. 模型能力商品化：基础模型差异缩小，价值向数据、分发和工作流迁移。
4. 物理 AI 起飞：机器人硬件、模型与数据共同越过部署阈值。

## 领先指标

- Agent 真实任务成功率
- 同等能力推理成本
- 企业 Agent 渗透率
- 机器人真实环境成功率
- AI 基础设施资本开支
- 高风险行业监管可部署性

## 商业策略

优先寻找那些即使模型变得更强、更便宜，需求反而会被放大的机会。
