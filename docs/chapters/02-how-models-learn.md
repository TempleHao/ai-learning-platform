# 第 2 章：模型为什么能学会东西？

## 核心直觉

模型可以抽象为一个带参数的函数。训练就是根据数据与目标函数不断调整参数，让输出变得更好。

训练循环：
1. 输入数据
2. 前向计算得到预测
3. 计算 Loss
4. 反向传播计算梯度
5. 优化器更新参数

## 参数构成计算结构

参数是计算结构中的数值，单个参数无法对应成一条独立知识。

## Backprop

反向传播负责高效计算梯度；优化器利用这些梯度更新参数。

## 可复算的梯度更新（与网页 Mini Lab 一致）

设模型 ŷ = wx，样本 x = −2、−1、0、1、2，目标 y = 2x。平均平方误差：

Loss(w) = Σ(wx−2x)² / 5 = 2(w−2)²。

梯度 dLoss/dw = 4(w−2)。初始 w = −1、学习率 0.08 时：

- 初始 Loss = 18，梯度 = −12。
- 更新 w = −1 − 0.08 × (−12) = −0.04。
- 更新后 Loss = 2 × (−2.04)² = 8.3232。

网页先重置、再训练一步，数值应与上述结果一致。学习率临时改成 0.5 的纸面练习会得到 w = 5、Loss = 18，说明更新步长过大可能跨过最优点。上述结论仅针对这组线性数据与完整批次梯度。

## 训练误差与泛化

训练集用于拟合参数，验证集用于选择方案，最终测试集应在模型选择完成后独立使用。训练误差低并不能保证未见样本的表现。

两个模型 A = 2x 与 B = 2x + (x−1)(x−2)，在训练点 (1,2)、(2,4) 上都零误差；面对留出的 (3,6)，A 预测 6，B 预测 8。这个例子说明需要保留独立样本检验。

现实迁移：预测下月商户拒付率，应按时间切分训练、验证、测试，控制重复商户记录和延迟出现的拒付标签造成的数据泄漏，并评估新商户与已见商户的分布差异。

## Training vs Inference

训练改变权重且成本高；推理通常固定权重，对每次新输入生成输出。商业上，训练决定前沿模型门槛，推理决定规模化应用的单位经济性。

## Token / Embedding / Transformer

文本被 tokenization 转换为离散单位，再映射为 embedding 向量。Transformer 通过 attention 让位置之间动态交换上下文信息。

## Pretraining / Post-training

现代大模型通常经历大规模预训练，再通过指令微调、偏好/强化后训练以及推理时工具与检索等方式塑形。

## 为什么模型会犯错

模型学习数据分布并生成概率输出，因此会出现幻觉、分布外失效、非确定性与能力锯齿。真实产品还会引入检索、工具、权限和下游系统错误。
