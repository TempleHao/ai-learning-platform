# 第 2 章：模型为什么能学会东西？

## 核心直觉

模型可以抽象为一个带参数的函数。训练就是根据数据与目标函数不断调整参数，让输出变得更好。

训练循环：
1. 输入数据
2. 前向计算得到预测
3. 计算 Loss
4. 反向传播计算梯度
5. 优化器更新参数

## 参数不是事实数据库

参数是计算结构中的数值，不是一条参数对应一条知识。

## Backprop

反向传播负责高效计算梯度，而不是整个学习算法本身。优化器利用梯度更新参数。

## Training vs Inference

训练改变权重且成本高；推理通常固定权重，对每次新输入生成输出。商业上，训练决定前沿模型门槛，推理决定规模化应用的单位经济性。

## Token / Embedding / Transformer

文本被 tokenization 转换为离散单位，再映射为 embedding 向量。Transformer 通过 attention 让位置之间动态交换上下文信息。

## Pretraining / Post-training

现代大模型通常经历大规模预训练，再通过指令微调、偏好/强化后训练以及推理时工具与检索等方式塑形。

## 为什么模型会犯错

模型学习数据分布并生成概率输出，因此会出现幻觉、分布外失效、非确定性与能力锯齿。真实产品还会引入检索、工具、权限和下游系统错误。
