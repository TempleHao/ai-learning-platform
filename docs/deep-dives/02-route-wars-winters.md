# Deep Dive 02：AI 路线战争、寒冬与复兴

## 核心命题
路线兴衰由算法、数据、算力、传感器、工程成本、市场与融资条件共同决定。

## 五条主路线
- Symbolic
- Connectionist
- Probabilistic
- Statistical Learning
- Reinforcement Learning

## AI Winter
不能简化为“符号主义失败”。核心包括实际应用不足、知识工程瓶颈、硬件与环境 grounding 限制、不确定性处理不足、预期过高与融资回撤。

## 统计转向
1988 Pearl 概率推理；1995 SVM；互联网时代数据、存储、计算与在线反馈使统计学习成为工业方法。

## 神经网络复兴
1986 backprop 早已存在；2012 之所以形成拐点，是大规模数据、GPU、深层架构、软件与云共同成熟。

## 最终是融合
现代系统通常组合 Neural + Search/Planning + Probability + Rules + RL/Feedback。
