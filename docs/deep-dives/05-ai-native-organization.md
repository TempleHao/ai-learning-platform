# Deep Dive 05：AI-native Organization

## 核心思想
不要直接问“AI 会不会取代这个岗位”。岗位由不同任务组成，AI 对任务的自动化 / 增强能力不同。

## Exposure ≠ Replacement
ILO 2025：全球约四分之一劳动者所在职业有一定 GenAI 暴露，但工作转型比整体替代更可能。

## 任务分配六变量
结构化程度、可验收程度、错误代价、异常率、隐性知识、系统接入。

## 组织变化
- 管理半径扩大
- 人从执行转向目标、Eval、异常与责任
- 初级岗位 / 人才梯队可能被重构
- 新角色：Workflow Architect、Agent Operator、Eval Engineer、Domain Reviewer、AI Product Owner、AI Governance

## 责任
区分任务 Owner、Operator、Approver、Accountable。

## 企业迁移四阶段
个人工具化 → 团队 Workflow → Agent 托管部分流程 → 组织重构。

## 2026 信号
- ILO：约 1/4 劳动者所在职业有 GenAI 暴露
- Stanford：32% 组织预计未来一年 AI 会减少员工规模；43% 预计变化很小
- 88% 组织使用 AI，但多数业务职能 Agent 部署仍在个位数

## Sources
ILO 2025; Stanford AI Index 2026 Economy; OpenAI Business Leader’s Guide to Agents.
