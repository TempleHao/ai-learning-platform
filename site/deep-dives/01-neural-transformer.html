DEEP DIVE 01

神经网络、Transformer
与 Scaling

你不需要先成为算法工程师，但如果想成为真正的 AI 运用层专家，必须能看懂大模型内部的几个关键结构：参数如何组合成层、层如何形成表示、Attention 如何交换上下文，以及规模为什么会持续带来能力变化。

直觉知道“神经元、层、表示、残差、Attention”分别在做什么。
结构能画出一个简化 Transformer Block。
趋势理解 Scaling、MoE、推理时计算和效率优化为何重要。
D1.1 · NEURON

一个“神经元”本质上仍然是加权求和 + 变换

最简形式z = w₁x₁ + w₂x₂ + … + b

输入 x 代表特征，权重 w 决定每个特征影响多大，b 是偏置。单个线性单元能力很有限，但大量单元组成多层网络，并加入非线性激活后，就可以表示非常复杂的函数。

运用层需要抓住的点

“参数很多”不是为了存很多独立答案，而是让模型拥有更大的函数表示能力；真正的知识和能力分布在大量参数共同形成的计算结构中。

D1.2 · NONLINEARITY

没有非线性，再多层也只是一个更大的线性函数

如果每一层都只做线性变换，多层可以数学上合并成一层。激活函数引入非线性，让网络可以形成弯曲、分段和复杂的决策边界。

LINEAR

只能组合成直线/平面

表达简单关系很有效，但无法表示复杂模式。

NONLINEAR

可以逐层构造复杂函数

神经网络因此能从像素、声音或 Token 中形成多层抽象。

D1.3 · REPRESENTATION LEARNING

深度学习最关键的变化：特征不再主要由人手工设计

传统机器学习经常依赖人先定义“哪些特征重要”；深度学习则让网络自己学习中间表示。

Raw原始像素 / Token / 波形
Low边缘 / 局部模式 / 子词关系
Mid形状 / 语法 / 语义关系
High物体 / 概念 / 任务相关表示

这也是“Embedding”重要的原因：离散对象被映射到连续向量空间，后续层可以对这些表示进行组合和变换。

D1.4 · ARCHITECTURES

不同架构，其实是在给模型不同“归纳偏置”

CNN

卷积网络

利用局部连接和共享权重，特别适合图像中的局部空间结构。

RNN / LSTM

循环网络

按序列一步步传递状态，适合语言和时间序列，但长距离依赖与并行训练较难。

Transformer

Attention 驱动

让序列位置直接彼此交互，更适合并行和大规模训练。

Transformer 的成功并不意味着 CNN / RNN 的所有思想“错误”，而是它在大规模通用序列建模上更适合当时的数据与硬件条件。

D1.5 · ATTENTION

Attention 的本质：当前 Token 应该从别的 Token 取多少信息？

经典写法Attention(Q,K,V) = softmax(QKᵀ / √d) V

可以把 Q 看成“我在找什么”，K 看成“我能提供什么线索”，V 看成“真正要传递的信息”。Q 与 K 的匹配决定权重，再用这些权重加权汇总 V。

句子：“银行在河边，因为它附近有一座桥。”

真实模型不是简单地“找代词指代”，而是在很多 Attention Head 中同时学习不同关系。不同 Head 可能关注位置、语法、实体、局部模式或其他模型自行形成的结构。

D1.6 · TRANSFORMER BLOCK

一个 Transformer Block 可以先记成四件事

输入表示
→
Self-Attention
→
Residual + Norm
→
MLP
→
Residual + Norm

现代模型具体顺序和实现会变化，但这个简图足以理解大多数讨论。残差连接之所以重要，是因为它让深层网络更容易优化；ResNet 早期已经展示了残差学习对于训练很深网络的重要性。

D1.7 · SCALING

为什么行业曾经疯狂“做大”？因为性能提升表现出可预测的 Scaling 规律

2020 年 Scaling Laws 工作显示，语言模型 Loss 会随模型规模、数据规模和训练计算量按较稳定的幂律趋势下降。这给产业一个极强信号：只要继续投入更多计算和数据，性能很可能继续提升。

Parameters更大的函数容量
Data更多模式与世界信息
Compute允许更大模型在更多数据上训练
Quality高质量数据和后训练决定“学到什么”

但“参数越多越好”仍是错误理解。2022 年 Chinchilla 工作强调，在固定计算预算下，模型大小和训练 Token 数需要更合理配比；一个更小、训练数据更多的模型可以胜过更大的但训练不足的模型。

D1.8 · MIXTURE OF EXPERTS

MoE：参数可以很多，但一次不必全部激活

普通稠密模型通常每个 Token 都经过同一组参数。Mixture-of-Experts 会根据输入路由到部分“专家”子网络，从而让总参数规模增加，而单次计算只激活其中一部分。

直觉“拥有更多专业团队”，但每个任务只叫相关团队来处理。

Switch Transformer 等工作展示了稀疏激活在扩大参数规模与控制计算成本之间的潜力，但也带来路由、通信、负载均衡和训练稳定性等工程复杂度。

D1.9 · INFERENCE-TIME COMPUTE

能力提升不只来自“训练更大”，也来自“回答时多花计算”

传统理解里，训练结束后模型能力大致固定。但推理阶段可以通过多步思考、搜索、验证、工具和候选答案比较，把更多计算投入到单个问题。

TRAIN-TIME SCALE

训练时投入更多

更大模型、更多数据、更长训练，成本集中在预训练阶段。

INFERENCE-TIME SCALE

回答时投入更多

复杂问题多跑步骤、搜索、验证或工具，成本按任务发生。

这会改变 AI 的经济学：同一个模型可以对简单问题快速便宜回答，对高价值难题投入更多推理预算。

D1.10 · EFFICIENCY

前沿不只有“做大”，还有“把同样能力做便宜”

Distillation让较小模型学习大模型能力。
Quantization降低数值精度，减少显存和计算。
Pruning / Sparsity减少不必要计算或连接。
Caching复用重复上下文和中间结果。
Routing简单任务给小模型，难题再给大模型。
Specialization小而专的模型在特定任务可能更经济。
为什么运用层必须懂这些词

它们最终会决定推理价格、设备端部署、隐私、本地化和某些 AI 产品是否能形成正毛利。

D1.11 · SELF CHECK

深潜自测

Q1：为什么“模型参数 = 知识数据库”是错误类比？

参数共同定义一个计算函数和表示空间，知识分散编码在大量权重交互中，并不能像数据库行那样逐条读取。

Q2：Attention 的 Q / K / V 可以怎样理解？

Q 表示当前位置想找什么，K 表示其他位置提供什么匹配线索，V 是被加权汇总的实际信息。

Q3：Scaling Laws 为什么对产业资本开支如此重要？

因为它让“投入更多计算、模型和数据通常能换来更低 Loss / 更高性能”变得相对可预测，从而支持巨额基础设施投资。

Q4：MoE 为什么可能让“参数数”和“单次计算量”脱钩？

因为每个输入只路由到部分专家参数，而不是激活整个模型。
