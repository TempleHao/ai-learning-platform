LAB 01
CONTEXT

同一个任务：Prompt vs Context Engineering

选一个你真实做过的研究/分析任务。第一轮只写详细 Prompt；第二轮额外提供结构化背景、目标、历史决策、样例和必要文件。比较两轮结果。

产物两组输入、两组输出、差异表、你的结论。验收你能指出至少 3 个由 Context 改善带来的变化，并与模型能力变化明确区分。
LAB 02
STRUCTURED OUTPUT

把自然语言变成可供程序消费的数据

找 20 条半结构化文本，例如订单、客户需求、会议记录或商品信息，让模型稳定抽取成固定 JSON Schema。

产物Schema、20 条样本、解析结果。验收JSON 全部可解析；关键字段正确率有人工检查记录；异常输入有明确处理。
LAB 03
RAG

做一个“只基于资料回答”的知识库

选择一组你熟悉的文档，完成切块、检索、上下文组装和带来源回答。核心验收只有一个：检索必须稳定命中正确证据。

产物文档集、至少 30 个问题、检索结果、回答和引用。验收分别记录 Retrieval 命中率和最终 Answer 正确率，不把两者混在一起。
LAB 04
TOOLS + WORKFLOW

让模型真正调用一个外部工具

让模型负责判断意图和参数，让确定性工具负责执行，例如计算器、数据库查询、网页搜索、日历或内部 API。

产物工具定义、参数 Schema、调用日志、错误路径。验收模型不能靠“编造工具结果”完成任务；工具失败时系统有清晰反馈和停止机制。
LAB 05
EVAL

给你的 AI 系统建立回归测试

把前面任意一个项目变成可评测系统。收集至少 30 个代表真实任务分布的案例，并明确成功标准。

产物Eval dataset、评分规则、Baseline、改版结果。验收改 Prompt / 模型 / RAG 后能一键或半自动重跑，并看出提升还是回归。
LAB 06
AGENT

构建一个会“观察—行动—检查”的 Agent

选择开放路径任务，例如跨多源研究、代码修复或软件操作。Agent 可以动态选工具，但必须有限权、有限步数、有日志。

产物Agent Loop、工具、状态、检查点、停止条件、20 个任务。验收报告任务成功率、平均步骤数、失败类型和人工接管位置；不能只展示一次成功 Demo。
CAPSTONE
SHIP

发布一个真实 AI 产品

选择一个真实用户和真实问题。至少包含：模型、Context/Data、一个可验证的系统能力，以及 Eval。是否使用 RAG、Tool 或 Agent 由任务决定，不为了堆技术而堆技术。

必须回答谁用？为什么付出时间/金钱？Baseline 是什么？AI 提升多少？最严重错误是什么？单位任务成本是多少？验收有可访问产品或可运行仓库；有真实使用反馈；有失败复盘；有下一版本决策。
LAB 08
AI CODING · SPECIALIZATION

把一个真实 Repo 改造成 Agent-ready

选一个已经存在、你真的会继续维护的项目。不要重新做 Demo：为它补 Mission、Agent Instructions、架构图、自动测试和一个可验收 Issue，然后让 Coding Agent 完成该 Issue。

产物README/Mission、AGENTS.md 或等价规则、架构图、至少 3 个自动测试、1 个真实 Issue、Agent PR / Diff、复盘。验收你能证明 Agent 的改动通过测试；能指出至少一个 Agent 猜错的地方，并把教训沉淀为仓库级 Context。

LAB 09
KNOWLEDGE SYSTEM · SPECIALIZATION

做一个可信 RAG / 企业知识库

使用真实文档，避开玩具数据。把 Retrieval 和 Answer 分开评测，并加入 Metadata / 权限与文档更新测试。

产物30–100 份真实资料、Metadata 方案、30 个问题 + 正确证据、Retrieval Eval、Answer Eval、权限过滤、版本更新测试。验收能明确区分“没找到证据”和“模型没用好证据”；旧文档更新后不会继续主导答案；证据不足时能拒答。
先学习 Deep Dive 07 · Knowledge Systems →
LAB 10
MULTIMODAL · REALTIME SPECIALIZATION

做一个真正有必要使用语音 / 视觉的实时助手

选一个“如果只用文字会明显更差”的真实场景。设计 Mic / Camera / Screen 输入、Realtime / Chained 架构、打断机制、延迟指标和隐私边界。

产物场景定义、输入流图、架构选择、10 个真实任务、延迟记录、隐私规则、文字版 vs 多模态版对比。验收用数据证明多模态带来实际收益：完成率、时长或体验至少一项明显优于文字基线，并能解释代价与风险。
