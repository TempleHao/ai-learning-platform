CHAPTER 00

AI 世界全地图

这一章不追求让你“会一个模型”，而是先让你知道：整个 AI 世界里到底有哪些东西，它们是什么关系，你现在站在哪里。

学完你应该能：用自己的话解释 AI / ML / DL / LLM / Agent / Robotics 的关系。
你不需要先会：高等数学、Python、神经网络公式或模型训练。
本章核心动作：建立“包含关系”和“系统关系”，以后所有新名词都往这张图上放。
先记住一句话

AI 不是一个产品，也不是一个模型。它是一个很大的目标与技术集合：让机器完成过去需要人类智能才能完成的任务。

初学 AI 最容易犯的错误，是把 ChatGPT、LLM、生成式 AI 和“人工智能”画上等号。实际上，今天最热门的大语言模型只是 AI 历史中的一条强势技术路线和一种重要产品形态。

你以后看到任何新名词，都先问三个问题：它属于技术方法、模型能力，还是产品/系统形态？它依赖什么？它解决什么问题？只要这三个问题能回答，热点就不会把你带乱。

0.1 · DEFINITION

AI 到底是什么？

NIST 对 AI 的定义之一，是一种机器系统：针对人类定义的目标，产生影响现实或虚拟环境的预测、建议或决策。这个定义有一个很重要的好处——它没有把 AI 限定为“像人一样聊天”。

AI 的核心不是“像不像人” 而是：机器能否感知 → 表示 → 学习/推理 → 决策 → 行动。

因此，垃圾邮件分类器、搜索排序、自动驾驶感知系统、围棋程序、语音识别、推荐系统、大语言模型和机器人，都可以属于 AI。它们“智能”的表现完全不同。

0.2 · HIERARCHY

第一张必须刻进脑子里的图：包含关系 ≠ 演进顺序

Artificial Intelligence · AI最大集合：让机器表现出智能能力
Machine Learning · ML让系统从数据中学习规律，而不是把全部规则写死
Deep Learning · DL以多层神经网络为核心的一大类机器学习方法
Foundation Models大规模预训练，可适配大量下游任务
Large Language Models · LLM以语言/Token 序列为核心对象的一类基础模型
注意

Agent、RAG、Multimodal、Reasoning、Robotics 并不能简单继续塞进上面的“俄罗斯套娃”。它们更多是能力、系统架构或应用形态。比如 Agent 可以使用 LLM，也可以调用搜索、数据库和软件工具；机器人则是 AI 与物理硬件结合的系统。

0.3 · SYSTEM THINKING

把“模型”和“AI 产品”分开，是成为运用层专家的第一步

用户体验层聊天界面 · IDE · 企业软件 · 机器人 · 工作流
Agent / 应用层任务拆解 · 记忆 · 权限 · 工具调用 · RAG · 工作流
模型层LLM · Vision · Speech · Embedding · Reward / World Model
训练与数据层预训练 · 后训练 · 数据 · 评测 · 人类反馈
计算基础层GPU / Accelerator · HBM · 网络 · 数据中心 · 电力

很多商业误判都来自把“模型能力”当成“产品价值”。一个模型即使能力很强，也不意味着企业会直接得到价值。真正落地时还需要数据接入、权限、流程设计、可靠性、评测、成本控制和用户界面。

商业视角

模型越强，某些应用层功能会被模型原生能力“吞掉”；但同时，更强模型也会让以前不可行的新工作流变得可行。机会往往出现在这两个力量之间。

0.4 · CAPABILITY MAP

AI 的能力不是一条直线，而是一张“能力树”

Perception

感知

视觉、语音、传感器，让机器把现实世界转化为可处理的信息。

Language

语言

理解、生成、翻译、总结、对话和结构化表达。

Prediction

预测

分类、排序、推荐、风险评分、时间序列和需求预测。

Generation

生成

文本、图像、音频、视频、3D、代码以及其他数字内容。

Reasoning

推理与规划

多步问题、数学、代码、搜索策略、计划与决策。

Action

行动

调用软件工具、操作电脑、执行工作流，最终进入物理世界。

从应用角度看，最关键的变化不是“模型答题分数又涨了多少”，而是能力链逐渐变长：过去 AI 多数只负责预测一个答案，今天越来越多系统开始理解任务 → 规划 → 调工具 → 检查结果 → 继续行动。

0.5 · HISTORY IN ONE PAGE

先看一条极简历史线，后面再展开技术路线战争

1950s“机器能否思考？”成为正式科学问题；1956 年 Dartmouth 会议确立 Artificial Intelligence 这一研究领域。
1960s–1980s符号主义、搜索、专家系统占据重要位置：知识和规则主要由人写进去。
1990s–2000s统计机器学习壮大：从“写规则”逐渐转向“从数据里学规律”。
2010s算力、数据与深度神经网络结合，视觉、语音等领域出现突破。
2017Transformer 提出，用注意力机制重构序列建模方式，后来成为大语言模型的关键基础。
2020s基础模型与生成式 AI 普及；能力从内容生成扩展到推理、工具使用、Agent 与多模态交互。

真正重要的不是年份，而是每次范式变化背后的问题：智能应该由人写规则，还是由机器从数据里学？应该做专用系统，还是做通用模型？应该只输出答案，还是拥有行动能力？

0.6 · FRONTIER SNAPSHOT · 2026

今天我们站在哪里？

把前沿数据放进单独的 Frontier 层，是为了以后更新它，而不破坏基础课程。Stanford 2026 AI Index 显示，前沿模型仍在快速提升；Agent 在真实计算机任务上的表现显著进步，但仍明显不可靠；机器人在开放的真实家庭环境里则远未达到通用水平。

≈66%OSWorld 上 Agent 完成计算机任务的成功率量级说明：已经从“回答问题”进入“操作电脑”，但仍会大量失败。
≈12%真实家庭任务中的机器人成功率量级说明：数字世界的 Agent 进步，远快于开放物理世界。
88%组织层面报告使用 AI 的比例说明：使用已经普及，但“使用 AI”不等于完成深度流程重构。
你应该形成的判断

2026 年最值得关注的主线，不再只是“模型会不会说”，而是：模型能否可靠地推理、使用工具、持续执行任务，并进入企业流程与物理世界。

0.7 · MISCONCEPTIONS

七个必须尽早纠正的误区

误区 1：AI = ChatGPT

ChatGPT 是 AI 产品；LLM 是其核心模型技术之一；AI 的范围远大于两者。

误区 2：大模型就是数据库

模型参数不是一个可以逐条查询的事实表。模型通过训练形成统计表示，因此会“会说但说错”。

误区 3：参数越多一定越聪明

规模很重要，但数据、训练方法、架构、后训练、工具、推理策略和评测同样重要。

误区 4：Benchmark 高 = 工作中一定好用

真实工作还有上下文、权限、流程、可靠性、成本、延迟和异常处理。

误区 5：Agent 就是会自动回复的机器人

Agent 的关键是围绕目标持续选择行动、调用工具、观察结果并继续执行。

误区 6：AI 进步是匀速的

不同能力发展极不均衡，会出现“数学很强但简单感知任务很差”的锯齿状前沿。

误区 7：懂 AI 就必须先学会训练模型

对运用层专家而言，更重要的是理解能力、系统结构、数据、评测、经济性和边界。

0.8 · LAB 00

第一个练习：给所有 AI 名词“找位置”

接下来一周，只要你看到一个 AI 新名词，就不要先背定义。先把它放进下面四个抽屉中的一个或多个：

A · 技术方法如 Transformer、强化学习、蒸馏
B · 模型/能力如 LLM、Vision Model、Reasoning
C · 系统架构如 RAG、Agent、Memory、Tool Use
D · 产品/产业如 Copilot、机器人、AI 搜索、垂直 SaaS
0.9 · SELF CHECK

本章自测：不是背定义，而是检查地图是否建立

Q1：为什么“LLM ⊂ AI”是对的，但“Agent ⊂ LLM”不准确？

LLM 是 AI 模型的一类；Agent 更像系统架构，可以把 LLM 作为决策核心，也可以同时使用搜索、数据库、代码执行和其他模型，因此不是单纯的模型包含关系。

Q2：为什么模型能力提升，不等于商业价值自动提升？

真实价值还取决于数据接入、工作流、权限、安全、可靠性、成本、分发和组织变革。模型只是系统的一层。

Q3：为什么 2026 年 Agent 是一个比“聊天机器人”更重要的观察方向？

因为能力正在从生成答案向执行任务迁移。能否稳定操作软件、调用工具、完成长任务，会直接决定 AI 能否进入更大规模的真实生产流程。
