CHAPTER 05

AI 商业机会
与未来情景

“AI 很火”不是商业判断。真正要问的是：新增价值在哪里产生？哪个环节暂时稀缺？谁拥有分发、数据、工作流和资本？当基础模型继续变强时，这个利润池会扩大、迁移还是消失？

产业视角看懂电力、芯片、云、模型、Infra、应用和机器人之间的价值传导。
公司视角用护城河、单位经济性和模型吞噬风险判断项目。
未来视角不用单线 AGI 预测，而用情景树和领先指标更新判断。
商业判断的底层公式

机会质量 ≈ 市场价值密度 × AI 带来的能力跃迁 × 可占有利润 × 持续壁垒 ÷ 执行与资本风险。

技术越热，越需要区分“社会价值”与“可被某家公司长期捕获的利润”。一个技术可以极大提升生产率，却因为竞争、开源、模型商品化或分发平台抽走价值，而让应用公司很难赚钱。

5.2 · BOTTLENECKS

利润池通常向“最稀缺的瓶颈”移动

产业发展初期，最稀缺的东西往往拥有最强议价权。AI 训练扩张时可能是先进芯片、HBM 和数据中心；模型能力趋同后，价值可能向分发、专有数据、工作流和结果责任迁移。

供给受限先进芯片、HBM、电力、土地、人才

稀缺时容易形成高利润，但也吸引大规模资本扩产。

技术难度前沿训练、推理优化、安全、机器人

难复制带来壁垒，但技术迭代可能迅速重置领先。

分发稀缺操作系统、办公套件、搜索、CRM、开发者入口

已有用户入口能把新 AI 功能低成本分发给亿级用户。

数据 / 工作流稀缺企业私有数据、行业流程、许可与责任

越接近真实业务结果，通用模型越难单独替代。

但瓶颈会移动

今天的高毛利环节可能因为扩产、开源、标准化或模型进步迅速商品化。投资和创业判断必须看“瓶颈还能维持多久”。

5.3 · OPPORTUNITY ZONES

十类机会，不代表十类都同样适合创业

基础设施扩容电力 / DC / Cooling

资本重、周期长，但 AI 扩张会传导到物理基础设施。

计算供应链Chip / HBM / Network

技术和资本壁垒高，利润集中，但供应链与周期风险大。

推理降本Serving / Routing / Small Models

当调用规模扩大，单位推理成本本身就是巨大市场。

可信 AI InfraEval / Security / Observability

Agent 越深入生产，测试、权限与审计越刚需。

垂直 Copilot专业知识工作

先增强专家，不急于完全自动化，更容易跨过可靠性门槛。

垂直 Agent流程执行

价值更高，但要解决权限、数据、责任和长任务成功率。

AI-native Service按结果收费

用 AI 重构服务交付成本，而不是只卖软件账号。

RoboticsPhysical Labor

市场巨大，但可靠性、硬件、现场部署和售后极重。

AI for Science研发生产率

价值密度极高，但验证周期、专业门槛和监管也更高。

新分发入口Agent / Search / OS

如果用户从“点 App”转向“给 Agent 下目标”，现有软件分发格局可能重排。

5.4 · MOATS

AI 时代，最脆弱的护城河是“我会调用一个模型 API”

弱Prompt / UI 包装

容易复制，基础模型升级可能直接吸收功能。

中工作流集成 / 体验 / 品牌

更靠近用户习惯，但仍可能被大平台分发优势挤压。

强专有数据 / 反馈闭环 / 权限入口

使用越多越能积累特定任务优势。

更强系统-of-record / 责任 / 网络效应

掌握关键业务记录、许可、交易关系或结果责任，迁移成本更高。

“模型吞噬风险”指的是：今天你收费提供的功能，下一代基础模型可能直接原生支持。真正稳健的产品要问：即使底层模型能力翻倍，我的价值是否反而增加？

5.5 · UNIT ECONOMICS

AI 软件不一定天然拥有传统 SaaS 的边际成本结构

单位贡献利润= 收入 − 推理 − 检索/工具 − 重试 − 人审 − 错误损失 − 服务成本

传统 SaaS 增加一个用户的计算成本通常相对低；生成式 AI 和 Agent 每一次使用都可能产生显著推理、搜索、工具和长任务成本。因此“收入增长很快”不等于商业模式已经成立。

运用到公司分析

看 AI 公司不能只看 ARR。要看每次任务真实成本、模型降价能否传导给公司、是否需要大量人工兜底、客户愿意为“结果”还是“席位”付费。

5.7 · SCENARIO TREE

不要预测一个未来，至少准备四个世界

A

模型快速商品化

开源与闭源能力趋同、价格持续下降。

受益：应用、分发、服务重构、推理规模。风险：纯模型溢价和薄包装应用。
B

Agent 可靠性跨阈值

长任务成功率、电脑操作和工具调用显著提升。

受益：企业自动化、Agent Infra、AI-native Service。风险：传统按席位收费的软件。
C

Physical AI 加速

机器人和自动驾驶的泛化、成本与安全快速改善。

受益：传感器、机器人供应链、制造、物流、能源。风险：物理劳动密集型商业模式。
D

监管与主权碎片化

数据、本地部署、模型合规与国家算力政策分化。

受益：安全、治理、本地云、主权模型。风险：全球“一套模型一套产品”复制。
5.8 · LEADING SIGNALS

未来判断不要盯新闻标题，要盯领先指标

模型经济学每百万 Token / 每个任务的真实成本是否继续快速下降？
Agent 成功率长任务成功率、可恢复性和人类接管频率。
企业替换AI 是新增预算，还是开始替代软件席位、外包和岗位成本？
基础设施GPU/HBM 供给、电网接入、数据中心建设与利用率。
Physical AI真实环境成功率、硬件 BOM、维护和部署周期。
监管责任、版权、数据、模型审计和跨境限制是否改变单位经济性？
5.9 · FRONTIER SNAPSHOT · 2026

资本已经大规模下注，但商业兑现仍高度不均

Stanford 2026 AI Index 统计，2025 年全球企业 AI 投资达到约 5816.9 亿美元，同比大幅增长；组织层面的 AI 使用率达到 88%，但 Agent 在多数企业职能里的实际部署仍处于个位数。这意味着“采用 AI”已经很普遍，但“把 AI 变成自主生产流程”仍处在早期。

与此同时，IEA 的《Energy and AI》基准情景预计，为数据中心供电所需的全球发电量将从 2024 年约 460 TWh 增至 2030 年超过 1000 TWh。AI 的经济影响因此会穿透软件，进入电力、建设、制冷和能源结构。

5.10 · LAB 05

选一个 AI 公司或机会，写一页“反营销”投资备忘录

禁止写“市场空间巨大、AI 改变世界”。必须回答：

5.11 · SELF CHECK

本章自测

Q1：为什么“市场很大”不等于“公司能赚钱”？

社会价值可能被客户、平台、基础模型、硬件供应商或竞争者分走。商业价值取决于公司能否长期占有利润，而不只是行业总价值。

Q2：什么是模型吞噬风险？

应用今天收费提供的功能，未来可能直接成为基础模型原生能力或平台免费功能，使产品差异化消失。

Q3：为什么 Agent 成熟可能冲击传统 SaaS 席位模式？

如果 Agent 能跨软件完成目标，客户购买价值可能从“给每个人一个软件账号”转向“直接购买完成的任务或结果”。

Q4：为什么 AI 机会必须看电力和数据中心？

训练和推理最终依赖物理算力与能源。规模扩大时，电网、冷却、土地和建设会成为真实约束和利润池。
