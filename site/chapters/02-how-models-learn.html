CHAPTER 02

模型为什么能学会东西？

这一章只建立一个底层直觉：模型并不是被“灌入答案”，而是在大量例子和反馈中不断调整参数，让预测越来越符合目标。

你会理解参数、训练、损失、梯度、反向传播和推理的关系。
你会看懂Token、Embedding、Attention、预训练和后训练在系统中的位置。
你暂时不用手算矩阵、微积分证明或自己训练大模型。
先记住一句话

模型可以先理解成：一个输入 → 输出的函数；“训练”就是寻找一组更好的参数，让这个函数在大量例子上表现更好。

无论是判断邮件是不是垃圾邮件、识别图片里是不是猫，还是让语言模型预测下一段文字，底层都可以抽象成同一个过程：输入信息，经过一组参数化计算，得到输出，再根据输出好不好调整参数。

2.1 · PARAMETERIZED FUNCTION

模型 = 一个带很多“旋钮”的函数

先想一个只有一个参数的模型：

预测：ŷ = w × x

如果真实世界的规律是 y = 2x，那么最好的参数就是 w ≈ 2。w 就像一个旋钮：太小会低估，太大会高估。

现代神经网络做的事情本质类似，只是“旋钮”不再是一个，而可能是数十亿甚至更多参数，并且它们之间通过很多层复杂计算相互作用。

参数不是“知识条目”

不能把 10 亿参数理解成 10 亿条事实。参数是模型内部计算结构里的数字，它们共同决定模型如何把输入映射成输出。

2.2 · TRAINING LOOP

训练的核心循环：预测 → 计算误差 → 调参数 → 再预测

① 输入数据x 与目标 y
→
② 模型预测ŷ = f(x; θ)
→
③ 计算 Loss预测离目标多远
→
④ 算梯度每个参数该往哪边改
→
⑤ 更新参数让下一次更好
MINI LAB

亲眼看一个参数被“训练”出来

目标规律固定为 y = 2x。模型一开始只有参数 w，预测公式为 ŷ = w × x。点击训练，观察 w 如何向 2 靠近。

当前参数 w-1.00
平均 Loss--
训练步数0
现在 w = -1，模型方向都猜反了。训练会根据误差来调整它。

这里的 Loss（损失函数）只是一个“有多错”的数字。训练算法的目标不是让模型理解“我错了”，而是把这个数字变小。

2.3 · BACKPROP

反向传播：高效计算“每个参数对错误负多少责任”

在深层神经网络里，一个输出往往经过很多层计算。模型出错时，我们需要知道：前面每一层、每一个参数如果稍微变化一点，会让最终 Loss 变大还是变小？

最实用的理解 Backprop 不是“学习本身”，而是高效计算梯度的方法。

梯度告诉优化器：哪些参数该增加、哪些该减小，以及敏感程度。Goodfellow、Bengio 和 Courville 的《Deep Learning》也特别区分了这两件事：反向传播负责计算梯度，优化算法再利用梯度更新参数。

Forward从输入算到预测和 Loss
→
Backprop从 Loss 反推参数梯度
→
Optimizer根据梯度更新参数
2.4 · TRAINING vs INFERENCE

训练和推理，是两种完全不同的经济活动

TRAINING

训练

用大量数据反复计算 Loss、梯度和参数更新，得到模型权重。

  • 计算量极大
  • 需要训练数据
  • 会改变模型参数
  • 一次训练可服务很多次使用
INFERENCE

推理

参数基本固定，输入新的 Prompt / 图片 / 数据，让模型产生输出。

  • 发生在每次实际使用时
  • 决定延迟与单位调用成本
  • 通常不改变基础权重
  • 规模化产品里成本可能极大
商业视角

训练成本决定谁能做前沿基础模型；推理成本决定 AI 产品能否大规模赚钱。未来硬件、模型压缩、缓存、路由和小模型的重要性，很大程度都来自推理经济学。

2.5 · TOKEN + EMBEDDING

语言先被切成 Token，再变成向量

语言模型不能直接处理“文字的意义”。它先把文字切成 Token。Token 不一定等于一个汉字或一个英文单词，它是模型词表里的离散单位。

原始文本“AI 正在改变软件”
→
Tokenization切成模型可识别的离散编号
→
Embedding编号映射成高维向量
→
Transformer让每个位置结合上下文更新表示

Embedding 可以理解成“把离散符号放进一个连续的高维空间”。相似的用法和语义可能形成相近的内部表示，但不要把它想象成一个简单二维词义地图。

2.6 · TRANSFORMER

Attention 的直觉：处理一个 Token 时，动态判断“该看上下文里的谁”

2017 年《Attention Is All You Need》提出 Transformer，核心创新之一是以 Attention 为中心处理序列。相比依赖循环一步步传递信息的架构，它更容易并行训练，也更适合规模扩张。

例句：“小王把杯子放到桌上，因为它很稳。”

小王杯子桌上因为它很稳
这里的“它”究竟指什么，需要结合上下文关系。Attention 的思想就是让当前位置动态聚合其他位置的信息。

Transformer 并不等于 LLM，但今天绝大多数主流 LLM 都建立在 Transformer 或其变体上。

2.7 · PRETRAIN + POST-TRAIN

大模型通常不是“一次训练完成”，而是多阶段塑形

1 · 预训练

在巨大语料上学习语言、知识、模式和广泛能力。通常是成本最高的阶段。

2 · 指令 / 监督微调

让模型更会理解人类任务格式和期望回答方式。

3 · 偏好 / 强化后训练

利用人类或模型反馈，让回答更有帮助、更安全、更符合目标。

4 · 推理时增强

搜索、工具、RAG、更长计算、Agent 工作流等，可以在不重新训练基础模型的情况下提升结果。

因此，当你比较两个 AI 产品时，不能只问“底层是什么模型”。同一个基础模型，在不同后训练、系统提示、工具、检索和工作流下，可以表现得像完全不同的产品。

2.8 · NEXT TOKEN PREDICTION

为什么“预测下一个 Token”会涌现出这么多能力？

语言里压缩了大量关于世界的信息：事实、因果、逻辑、人物行为、代码结构、数学表达、写作方式。如果模型要在极大规模文本上持续预测“接下来最可能是什么”，它就被迫学习大量隐含结构。

但不要神化

“预测下一个 Token”描述的是训练目标的一部分，不等于模型只会机械补词。复杂能力来自模型规模、数据分布、架构、优化和后训练共同作用；同时，这种训练目标也解释了为什么模型会生成“听起来合理但实际上错误”的内容。

从运用层看，这一点非常重要：LLM 首先是一个生成概率分布的模型，不是天然的事实数据库、搜索引擎或确定性规则引擎。

2.9 · WHY MODELS FAIL

理解训练方式，就能理解很多失败模式

幻觉

模型优化的是生成合理输出，不是“每句话必须来自数据库中的已验证事实”。

上下文失误

模型只看到当前提供的信息和内部参数，没有自动拥有完整企业背景与实时世界状态。

分布外问题

训练中很少见的输入、任务或环境可能让模型表现骤降。

非确定性

生成通常涉及概率采样，同一问题不一定每次得到完全相同结果。

能力锯齿

一个模型可能会高难度代码，却在简单计数、空间关系或特定边界条件上失败。

系统错误

即使模型本身正确，工具权限、检索数据、Prompt、解析器和下游软件也可能出错。

运用层专家真正关心什么？

不是“模型是不是聪明”，而是：在我的任务分布上，正确率多少？失败能否检测？错误代价多大？是否需要检索、工具、规则、人审或多模型协作？

2.11 · SELF CHECK

本章自测

Q1：参数、训练、推理三者分别是什么？

参数是模型内部可调整的数值；训练根据数据和 Loss 更新参数；推理是在参数基本固定后，用新输入计算输出。

Q2：反向传播是不是训练算法的全部？

不是。Backprop 负责高效计算梯度；优化器利用梯度更新参数；训练还包含数据、目标函数、批次、正则化等很多环节。

Q3：为什么 Token 成本会成为商业问题？

推理时输入和输出 Token 都需要计算。高频、大上下文、长输出的产品会放大单位调用成本和延迟。

Q4：为什么 RAG 和工具调用不是“模型训练”的同一件事？

它们通常是在推理时给模型提供外部信息或行动能力，并不必然修改基础模型权重。
