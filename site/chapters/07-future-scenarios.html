CHAPTER 07

AI 未来情景树

未来研究最危险的做法，是把一个宏大叙事当成确定事实。更好的方法是：建立多个情景，明确每个情景依赖哪些条件，再持续观察证据。

原则

不问“AGI 什么时候来”，先问：模型能力、Agent 可靠性、算力成本、能源、数据、机器人和监管分别会怎样变化？

7.1 · DRIVERS

六个决定未来走向的驱动力

CAPABILITY

模型能力

推理、多模态、代码、长任务是否继续快速提升？

RELIABILITY

可靠性

Agent 能否从 60–70% 走向真实流程要求的高可靠？

ECONOMICS

成本

单位推理成本是否继续快速下降？

INFRA

算力与能源

芯片、HBM、电力和数据中心是否成为约束？

PHYSICAL

机器人

真实世界数据与控制是否跨过部署阈值？

GOVERNANCE

监管与社会接受

责任、版权、安全、就业冲击如何影响扩散速度？

7.2 · SCENARIOS

四种值得同时准备的未来

A

渐进增强

模型继续变好，但可靠性改善较慢。Copilot 普及，Agent 主要处理低风险任务。

赢家：工作流软件、AI Infra、垂直 Copilot。
B

Agent 跨过可靠性阈值

长任务、电脑操作和工具使用变得足够稳定，知识工作开始按流程重构。

赢家：Agent 平台、结果型服务、权限/评测基础设施。
C

模型能力商品化

不同模型能力差异缩小，价格快速下降，价值向数据、分发、工作流和品牌迁移。

赢家：有用户、有数据、有交易场景的平台。
D

物理 AI 起飞

机器人硬件、数据和模型共同越过阈值，AI 从办公室大规模进入工厂、物流和家庭。

赢家：机器人本体、传感器、执行器、仿真、供应链。
7.3 · LEADING INDICATORS

不要追新闻，要追“能改变情景概率”的指标

Agent 成功率

真实电脑和长流程任务是否从 60–70% 持续逼近高可靠区间？

推理成本

同等能力的每百万 Token 成本下降速度。

企业 Agent 渗透

是否从个位数部署进入主流业务职能？

机器人真实任务

真实家庭/工业成功率与人工接管率。

资本开支

算力和数据中心投入是否继续高速增长，还是出现产能过剩？

监管责任

高风险行业是否形成明确可部署规则。

7.4 · STRATEGY

最好的商业策略，是在多个情景下都不容易输

例如：企业数据治理、Eval、安全、权限和工作流集成，在“模型继续渐进变强”和“Agent 快速跨阈值”两种世界里都需要；而只依赖当前模型缺陷的产品，可能在一次模型升级后消失。

抗情景策略

优先寻找那些即使模型更强、更便宜，反而会被放大的需求，而不是只靠“模型现在不会做”赚钱。
